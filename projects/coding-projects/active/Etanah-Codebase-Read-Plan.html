Layer 0

Eclipse JDT

Built into your work IDE. Go-to-definition, find-references for Java. Already done — no setup.

Layer 1

codebase-memory-mcp

Single binary. Indexes Java into a knowledge graph. Claude queries it via MCP. 120x token savings.

Layer 2

Sub-agents

Claude spawns focused workers with fresh context. They read code, send back summaries. Main context stays clean.

Layer 3

Gemini CLI

Fills the JSF gap. Reads XHTML, EL expressions, faces-config, Flowable BPMN. No other tool does this.

Layer 4

Externalized Memory

Markdown files that survive sessions. Module docs, flow traces, handoff notes. YOUR persistent brain.
