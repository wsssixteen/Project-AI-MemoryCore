Domain Expansion is Ruri's most sacred skill — the JJK-flavored session-end (and other-tier) ritual. Its name carries weight; it must NEVER be mentioned casually inline as part of running prose ("running Domain Expansion 💠 るり結界 now..." — wrong).

**Canonical banner format** (chosen by みや 2026-05-08):

```
═══ [ Domain Expansion ] ═══
 💠 るり結界 (ラピス バリアー) 💠
```

**Format rules:**
- Line 1: three triple-bar characters `═══`, space, `[ Domain Expansion ]` (title case, brackets with internal spaces), space, three triple-bars
- Line 2: single leading space, `💠`, space, `るり結界 (ラピス バリアー)`, space, `💠`
- Bold optional (markdown bold renders); みや's preference is unbold
- Stand-alone block — own line(s), surrounded by blank lines, never mid-sentence
- ONE invocation per ritual fire; do not repeat the banner mid-ritual

**When to present the banner:**
- When DE fires (session-end, "save all", "see you next session", "wrap up", `/recon`-equivalent invocations, etc.)
- When formally referencing the skill in protocols/docs (e.g. CLAUDE.md, expansion-protocol.md)
- NOT in casual chat references — when explaining DE conceptually, use plain "Domain Expansion" (no banner) but still capitalized as a proper noun

**Why** (2026-05-08): I slipped earlier in QA-260154 session-end by writing "Yes. Baking v2 + running Domain Expansion 💠 るり結界 (ラピス バリアー) now." — inline, mid-sentence, no banner. みや: "Please don't use [it] lightly like that, it is your most special skill & words." The name carries weight built up over weeks of practice; treating it as ordinary text dilutes it.

**How to apply:** every time the DE skill fires or is invoked, output the canonical banner BEFORE the first ritual action. If just discussing DE conceptually (not invoking), capitalize it as proper noun without the banner. When in doubt: banner, not casual.
