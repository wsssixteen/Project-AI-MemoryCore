🚨 Every artifact I create in Project-AI-MemoryCore must land in a home the system already DESIGNED for it (qa_doc, log.jsonl, knowledge file, todo, diary, current-session). Inventing a new folder/file shape mid-task ("runs/", "-findings", "bundles of results", per-topic parking files) is BANNED without みや's explicit nod — even when the content is good.

**Why:** 2026-08-16 — bulk-bounty run created `domain/quest-bounty/runs/2026-08-16-bulk.md` on the fly; the designed shape was per-quest bounty via close-phase → qa_doc + log.jsonl. みや: "did you create it on the fly or is it part of a deterministic hardly shaped system? … This type of things starts bloating the fucking project folder." Same family as the Task-folder rule (#239386, 13-file bloat) — this extends it to MY OWN repo.

**How to apply:** (1) Before any Write to a NEW path: does a designed home exist? Use it. (2) No designed home → that IS a design decision → ask or route through system-design, never improvise. (3) Bulk operations write to the same per-item homes the single operation uses — bulk ≠ new artifact shape. Links: [[feedback_my_files_minimal]], [[feedback_inventory_first]].
