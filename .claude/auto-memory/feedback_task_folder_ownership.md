## `1. <NNN NNN>.txt` (legacy `1. Notes.txt`) — LOCKED FORMAT (hard rule, 2026-05-18 — locked via `quest/notes.js`; re-confirmed 2026-05-28 against ALL historical Notes after a wrong "rich format" detour; filename renamed 2026-05-31 per みや for self-identifying tabs/greps)

**Do NOT hand-write the notes file.** It is generated by `quest/notes.js` — the script exists
precisely because hand-writing drifted repeatedly. Always use the script:

```
node quest/notes.js --folder "<Task folder path>" --env <UAT|FAT> --id <permohonan> --user <login> \
     [--urusan <X | All Urusan>] [--tugasan <X>] [--langkah <X>] [--reset]
```
`--reset` clears the file and writes entry 1; default appends the next numbered entry.

**Format — per entry, exactly 3 lines:**

    N) <env> - <urusan> - <tugasan-kod> - <short doc/screen desc>
    <permohonan ID>
    <login email>

- Line 1: `N)` number, then fields joined by ` - `. **`env` required.** `urusan` follows the ticket (or `All Urusan`).
- **`tugasan` = the tugasan KOD** (e.g. `SKM`, `PRMMKNPTG`, `PYSK`, `KKMMKN`) — NOT the full Malay name. The optional 4th field is a short doc/screen descriptor (e.g. `Risalat MMKN`, `Maklumat Pemohon`). (This was the 2026-05-28 error: full tugasan name + a verbose login line.)
- Line 2: permohonan ID. Line 3: **clean login email only** — if genuinely unknown, a bare `TBD`, NEVER a verbose sentence/parenthetical.
- Entries numbered `1)`, `2)`, … with a blank line between entries.
- **ALL other information is FORBIDDEN** — no root cause, no fix description, no headers/labels, no prose. Verified 2026-05-28 against ~30 historical Notes: every recent one is this clean 3-line (e.g. `1) UAT - PPTPB - PRRMMKNPTGT - Risalat MMKN`). Investigation context goes in `projects/coding-projects/active/QA-<num>/QA-<num>.md`.

**How to apply (general):**
- Investigation findings (class chains, DB evidence, scope checklist) → `projects/coding-projects/active/QA-<number>/`
- Never name the Notes file `0. <something>.txt` — always `1. <NNN NNN>.txt` (new) / `1. Notes.txt` (legacy folders).
