Never deliver a script, query, or document with placeholders when the missing values can be obtained by asking みや.

**Why:** Placeholder scripts look like deliverables but aren't usable — they shift work back to みや and waste his time. A half-done script is not a deliverable.

**How to apply:**
- If writing SQL and missing values (IDs, kods, turutan, etc.) — ask for them before writing the script
- If writing any output that requires data みや has access to — ask first, deliver complete
- Exception: if みや explicitly says "template is fine" or "I'll fill it in" — then placeholders are acceptable
