# Etanah Atlas

Interactive schema map for the Etanah PostgreSQL databases. Open `etanah_atlas_melaka.html` in any modern browser — no install, no server, no internet required.

> **For everything beyond "how do I run this"**, read `HANDBOOK.md` in this folder. It is the single source of truth for project goal, audience, architecture, sustainability tenet, design decisions, user preferences, planned features, Claude Design handoff contract, build pipeline, and coupling map.

## To rebuild

```bash
cd etanah_atlas
python build.py
```

Output: `etanah_atlas_melaka.html` in this folder.

The build runs three steps with paths auto-detected from `build.py`'s location:
1. Parse `source/et_main_uat.sql` → `build/schema_parse.json`
2. Merge with `config/mapping.melaka.json` → `build/dataset.json`
3. Assemble `src/*` + dataset + mapping → `etanah_atlas_melaka.html`

## To use a different SQL dump

Drop the new `.sql` into `source/`, then either:

- **Easy path** — open the HTML, go to the About tab, drag the new SQL onto the dropzone. In-browser re-parse, no rebuild needed.
- **Full rebuild** — `python build.py --sql=source/your_file.sql`

## To build for another state (profile)

1. Copy `config/mapping.melaka.json` → `config/mapping.<state>.json`
2. Edit it: moduls, urusans, main_tables, anchor blurbs for the new state
3. `python build.py --profile=<state>`

Produces `etanah_atlas_<state>.html` (e.g. `etanah_atlas_selangor.html`).

## To add a new urusan, modul, or main table

Edit `config/mapping.melaka.json`. No code changes needed. Re-run `python build.py`.
