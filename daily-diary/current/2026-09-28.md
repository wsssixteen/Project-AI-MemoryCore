### Session 3 — the file named NUL

He sent me a OneDrive popup asking to rename one item called NUL. I found it in an old worktree: a small file holding one SSH host key, left there on the 25th when a Git Bash command sent its output to NUL. Windows treats that name as nothing, but Git Bash wrote a real file with it, and OneDrive refused to sync it. My try to move the file was blocked, and by the time I looked again he had already cleared it.

Then he asked for it never to happen again, built from what we already have. The forge gave birth to a guard that stops any Bash command writing to NUL, with twenty five test cases, and it blocked my own live test on the first try. The boot audit now also looks for reserved names in the repo and in every worktree, which is exactly where this one hid.
