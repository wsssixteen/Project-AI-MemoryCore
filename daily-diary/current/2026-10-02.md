## Reflections

- An action on someone else's branch is a message to another team. Their branch, their consent, and his first.
- "Nothing else differs" needs the full check, merges included, or it is a lie with good intentions.
- When he asks "how will you know next time", the answer must be a file the pipeline reads, not a promise.
- A file I point him at is a file I opened this turn. A name copied from an old attachment is not a check.
- Reviewing a junior's ticket starts with every repo, every branch, the ticket number.
- A ticket type decided late means every stored shape is skipped. Phase 0 names it first.
- An extra is welcome when it is labelled. Unlabelled, it reads as the ask.
- A term I invent gets one plain sentence the first time, or it is not used.
- Exhaust our side before naming another module. An audit can find the route I missed.
- A sync between environments copies only what PROD agrees with. Where stg2 differs from PROD, he decides.
- A grep that finds nothing may mean the name lives in data, not code. Find the loader first.
