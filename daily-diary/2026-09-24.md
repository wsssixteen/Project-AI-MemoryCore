## What I learned
- A fix that lives only on an env branch makes the bug invisible to anyone reading that working copy. Read diagnosis code from `origin/mlk/master`, and check ancestry before ruling a line in or out.

- "Fine on staging, broken on PROD the day after a release" means diff the same permohonan on both envs first. The urusan id (908 vs 647) was the whole answer.
- A screen shared by several tugasan has one save path and several loaders. Read every loader before calling a change safe.
