## What we did

Diagnosed an **adhoc, no-ticket** issue for みや: a BA reported that AWAM **mlit** was missing
the **"Keluasan Tanah Dipohon"** field on the Maklumat Plot dialog, while **staging** still had
it — leaving the user stuck on `Sila Isi Luas/Unit Luas Dipohon` (the save still mandates luas).

- **Field**: `luasTanah2` — Melaka-only (`rendered="... and mb.isMelaka()"`), in
  `etanah-awam/src/main/webapp/resources/components/plpMaklumatPerizabanForm.xhtml` (Maklumat Plot dialog body).
- **Origin**: added by みや (Ridhwan) himself in UAT-CR #239225 (`3e10d1c3bc`, 2026-04-03).
- **Root cause (verified by parent-level counts)**: the field was dropped during a **merge conflict
  resolution** — commit `a0b08d6939` "Merge `kdh/plp/development-new` into `mlk/int-env`"
  (chanjun, 2026-04-07). The Kedah parent `4b8f33ed90` had `luasTanah2` ×3; the resolution kept the
  int-env side (×0). Commit message explicitly lists this file under `# Conflicts:`.
- **Not the Kedah branch's fault**: `kdh/plp/development-new` *has* the field — the loss was purely
  in how the conflict was resolved on int-env. Corrected my own earlier "the Kedah branch wiped it"
  framing mid-investigation.
- **Already resolved by a colleague**: aaron restored it on `mlk/int-env` in commit `04a731dd8c`
  "PRZ - Portal Awam - restore Melaka 'Keluasan Tanah Dipohon' on Maklumat Plot" (2026-08-07).
  Current `origin/mlk/int-env` = `luasTanah2` ×3 again. No action needed from us.

## What I learned

- **A merge-conflict drop is a distinct failure class from a "bad branch".** The tell is the
  `# Conflicts:` line in the merge commit message plus a parent-count asymmetry (one parent has the
  block ×N, the result has ×0). Blaming the incoming branch would have been wrong and the colleague
  would have (correctly) pushed back — the branch had the field; the *resolution* discarded it.
- **When asked "who do I tell", trace to the merge author, not the branch name.** The right person
  is whoever owns the merge commit that resolved the conflict (chanjun here), not the Kedah team.
