## What I learned
- Windows' notification platform remembers the first icon path it sees per app and re-reads that file's content. Re-point the path and you get nothing. Every serious app on this PC registers a PNG.
- A fix that touches a shared asset changes every consumer. I rebuilt the one ico three consumers read, to fix one of them.
- Ask "what does the existing thing already assert?" before believing a feature is covered. S10 was a test that documented the bug as intended behaviour.
